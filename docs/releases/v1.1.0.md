# Goal Prompt Template：执行模式与图文使用指南

v1.1.0 · 2026-10-19

这次更新让“生成提示词”和“执行最佳实践”有了明确的处理方式。

- 保留最终提示词和 `/goal` 模板。
- 明确要求执行时，理清目标后继续完成已授权任务，验证并交付结果。
- 检查和修复任务结合已有授权判断是否需要审批。
- 加入两张设置截图、可复制的个性化指令和中文界面说明。

## 设置截图

在 **设置 → 个性化 → 自定义指令 → Codex 指令** 中添加技能使用偏好。先安装技能，再添加指令。
